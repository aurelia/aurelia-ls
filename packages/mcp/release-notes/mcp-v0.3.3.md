# Aurelia MCP 0.3.3

- Reduced memory use when analyzing large shared data collections.
- Fixed tuple analysis and improved cache cleanup.
- Independent app entrypoints now require explicit aggregation with `applicationEntrypointPolicy: "aggregate-independent-graphs"`.

## Install

```sh
npm i -D https://github.com/aurelia/aurelia-ls/releases/download/mcp-v0.3.3/aurelia-ls-mcp-0.3.3.tgz
```

See the [provider setup guides](https://github.com/aurelia/aurelia-ls/blob/mcp-v0.3.3/packages/mcp/docs/providers/README.md) and the [MCP 0.3 protocol reference](https://github.com/aurelia/aurelia-ls/blob/mcp-v0.3.3/packages/mcp/docs/reference-v0.3.0.md).
