# Aurelia MCP 0.3.2

- Improved startup time, memory use, and cache reuse for template and diagnostic analysis in larger projects.

## Install

```sh
npm i -D https://github.com/aurelia/aurelia-ls/releases/download/mcp-v0.3.2/aurelia-ls-mcp-0.3.2.tgz
```

See the [provider setup guides](https://github.com/aurelia/aurelia-ls/blob/mcp-v0.3.2/packages/mcp/docs/providers/README.md)
and the [MCP 0.3 protocol reference](https://github.com/aurelia/aurelia-ls/blob/mcp-v0.3.2/packages/mcp/docs/reference-v0.3.0.md).
